# 透明悬停轮廓设计

## 目标

调整翻译小组件的视觉状态：鼠标离开控件时，窗口内容区域保持透明，仅显示圆角外轮廓；鼠标进入控件或键盘聚焦时，显示低透明度的半透明玻璃背景。译文和错误文本必须始终保持清晰可读。

## 约束

- 不修改 `TranslationCard`、`ConfigMenu` 的 Props 和现有窗口交互 API。
- 不通过父元素 `opacity` 控制透明度，避免译文、输入文字和按钮一起变淡。
- 保持窗口尺寸、拖动、关闭、最小化、置顶、设置和自动翻译行为不变。
- 使用 CSS 状态选择器完成切换，避免增加 React 状态和额外渲染。

## 实现设计

1. 将 `.desktop-stage` 和 `.translation-card` 的默认背景设为透明，只保留圆角边框和必要的命中区域。
2. 删除会形成第二层边框或顶部横线的舞台装饰、卡片伪元素和卡片顶部内高光。
3. 通过 `.translation-card:hover`、`.translation-card:focus-within` 恢复卡片背景、模糊和轻微阴影。
4. 保持 `.result-text`、`.error-message` 和输入文字使用不透明前景色；结果面板的顶部线条只在有译文、加载或错误状态时显示。
5. 使用现有的过渡动画，避免新增持续高频动画；在减少动态效果设置下继续关闭动画。

## 验证

- `cmd /c npm.cmd run build`
- `cmd /c npm.cmd run test -- --run`
- 检查源码中没有新增乱码字符，且公共 Props/API 未变化。
